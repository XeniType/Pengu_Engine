Dependencies

Conan is used, specifically the version 2.24.0, to obtain dependencies. It can be installed via the Conan website by following the installation guide at https://conan.io/.

And to run conan we also need to install python, we can install it by following the install guid on the web page https://www.python.org/.

In addition we need to install CMake version 3.27 were we can install it from the web page as well https://cmake.org/.

Compile

Open the tools folder and run genproject.bat to compile the project. Then, run each demonstrator from Visual.
